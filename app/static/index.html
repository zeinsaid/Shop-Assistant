  1. Shop Assistant

    An AI receptionist built for The Plug, a print shop next to the University of Nicosia. It answers customers from the shop's knowledge base and shows you why it replied the way it did.

    • It only answers from the shop's knowledge base, and must cite what it used. If it can't, it doesn't answer.
    • When it doesn't know, it asks the owner instead of guessing. Here, you get to play the owner.
    • Complaints, refunds and big orders go to a person.
    • The model was chosen by testing models from Anthropic, OpenAI and Google on 130 tricky customer messages.

    Waking up the assistant… This demo runs on free hosting that sleeps when nobody is using it, so the first visit can take about a minute.

Behind the reply

Every message gets exactly one action:

  • Answer from the shop's knowledge base, citing what it used.
  • Ask owner when the knowledge base doesn't cover it. It asks instead of guessing.
  • Hand off to a person for complaints, refunds and negotiations.
